# Netflix Global Content Intelligence Dashboard

## Overview
This project analyzes Netflix movies and TV shows using Python, SQL, and Tableau.

## Tools Used
- Python
- Pandas
- MySQL
- Tableau Public

## Features
- Content distribution analysis
- Genre trends
- Country-wise insights
- Ratings analysis
- Time-series trends
